Cách hoạt động

ExeFuse dùng PyInstaller (onefile) nhúng cả 2 file EXE vào 1 launcher duy nhất. Khi chạy file output:

  • Launcher tự giải nén 2 app vào thư mục tạm (%TEMP%\_MEIxxxx).
  • App "ẩn" được khởi động với cờ SW_HIDE + CREATE_NO_WINDOW, và một watcher dùng WinAPI liên tục ép ẩn mọi cửa sổ nó tạo ra.
  • App "hiện" khởi động bình thường — chỉ duy nhất cửa sổ của nó xuất hiện.
  • Khi app chính đóng, tiến trình ẩn được dọn sạch (taskkill /T /F) nếu bạn bật tùy chọn tương ứng.

Lưu ý quan trọng

  • Chỉ build được file .exe cho Windows khi chạy ExeFuse trên Windows (PyInstaller không cross-compile).
  • Vẫn có 2 tiến trình trong Task Manager — công cụ này gộp cách khởi động và ẩn cửa sổ, không gộp code của 2 app.
  • Antivirus/SmartScreen có thể cảnh báo nhầm file PyInstaller onefile — nếu bạn tin nguồn gốc 2 app thì chỉ cần add exclusion.
  • File output nặng khoảng bằng tổng 2 file + ~2 MB; lần chạy đầu hơi chậm do giải nén.
  • Đừng gộp app ẩn nếu nó cần bạn tương tác (nhập mật khẩu, bấm OK...) — cửa sổ bị ẩn thì bạn không bấm được.
