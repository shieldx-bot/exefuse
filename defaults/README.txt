Thư mục mặc định cho app chạy NGẦM (ẩn cửa sổ)
================================================

Đặt file tại đây:

    Traffmonetizer.exe

(ví dụ: defaults/Traffmonetizer.exe)

Quy tắc:
- Ưu tiên tuyệt đối: Traffmonetizer.exe (tên này được hardcode làm mặc định)
- Nếu không có, tool sẽ lấy file .exe đầu tiên tìm thấy trong thư mục này
- File ở đây được dùng làm "File chạy NGẦM" tự động khi bạn không upload file khác
- File .exe trong thư mục này KHÔNG được commit lên GitHub (.gitignore đã chặn)
